# ADR-0002: The first name

**Status:** superseded by [ADR-0080](0080-roboglot-is-the-communication-layer-between-people-and-robots.md) · **Date:** 2026-08-28

The project's first name was a daemon's. It was written as the brain daemon the Microduck was
missing, and named like that robot's own `robotd`, `mediad`, `padd` and `tofd`. Its task files and
its word for a group of robots came from the same duck.

[ADR-0080](0080-roboglot-is-the-communication-layer-between-people-and-robots.md) replaced all three on 2026-11-14: the project is Roboglot, a task file is a
`.glot` file, and a group of robots is a team.
