**There is no logo in this directory, and the README opens with its name.** A duck's head over
the title made Roboglot look like a toy rather than a tool that drives a real arm, so the README
lost it, and the social preview card built around it was deleted rather than redrawn.

Two files here are a real arm under a real cloud LLM: `lerobot.gif` and
`lerobot-what-it-saw.png`, OpenAI's `gpt-6-astra` on 2026-09-15. The page's screenshots are the
**scripted pilot**'s, and every row says so.

The hero is a phone pointed at a bench, so there is no script that re-records it, only the one
that re-cuts it: `lerobot_hero.py` takes a video and a run directory and neither is in this
repository. Re-recording it means an arm, an LLM and an afternoon, and the next person to spend
one is welcome to send a better clip.

**On upstream's assets.** No upstream mesh, policy, logo or brand asset is committed here, and
none ever will be.
