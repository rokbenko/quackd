# Licenses

Roboglot is eleven distributions built from this one repository: the core `roboglot`, and one
package per robot (`roboglot-microduck`, `roboglot-lerobot`, `roboglot-rosbridge`,
`roboglot-open-duck`, `roboglot-xlerobot`, `roboglot-alohamini`, `roboglot-toddlerbot`,
`roboglot-huebot`, `roboglot-moss`, `roboglot-rosarm`). All eleven are Roboglot's own Apache-2.0 code.
An extra named after a robot pulls that robot's package and whatever third-party library its
real backend needs, and `roboglot[robots]` pulls all ten. So the rows below name the distribution
each third-party library arrives with, which is no longer always the core.

An adapter published by somebody else is somebody else's code under somebody else's licence.
Roboglot finds one through the `roboglot.adapters` entry point group, so it can be installed and
driven without a pull request here, and nothing in the table above covers it: this repository
does not vendor it, does not lock it and makes no claim about its terms.

Contributions are accepted under Apache-2.0 (see `LICENSE` §5). Do not submit code or
assets you do not have the right to license that way — including upstream meshes.
