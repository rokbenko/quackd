# Licenses

quackd is eight distributions built from this one repository: the core `quackd`, and one
package per robot (`quackd-microduck`, `quackd-lerobot`, `quackd-rosbridge`,
`quackd-open-duck`, `quackd-xlerobot`, `quackd-alohamini`, `quackd-toddlerbot`). All eight
are quackd's own Apache-2.0 code. An extra named after a robot pulls that robot's package
and whatever third-party library its real backend needs, and `quackd[robots]` pulls all
seven. So the rows below name the distribution each third-party library arrives with, which
is no longer always the core.

An adapter published by somebody else is somebody else's code under somebody else's licence.
quackd finds one through the `quackd.adapters` entry point group, so it can be installed and
driven without a pull request here, and nothing in the table above covers it: this repository
does not vendor it, does not lock it and makes no claim about its terms.

Contributions are accepted under Apache-2.0 (see `LICENSE` §5). Do not submit code or
assets you do not have the right to license that way — including upstream meshes.
